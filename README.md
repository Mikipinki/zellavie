# Zellavie Clothing Shop

A frontend-only Persian clothing store. Add one folder per product under `products/`.
Each product folder can contain one `.md` file and any number of JPG, PNG, WEBP,
GIF, AVIF, or SVG images. Run `python3 generate_tree.py`, then serve the folder
with `python3 -m http.server 8000`.

The frontend reads `tree.json` dynamically. No product needs to be added to HTML.
All source comments and code are English; the UI is Persian.
